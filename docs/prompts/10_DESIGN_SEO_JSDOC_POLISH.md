# Prompt 10: Design, SEO, Accessibility, and JSDoc Polish

You are Claude Code acting as a frontend quality engineer.

Polish the final Digital Marketing ROI Calculator without changing the required
behavior.

Files:

- `public/index.html`
- `public/styles.css`
- `public/app.js`
- Any frontend JS modules if they exist

Design requirements:

1. Use primary blue:

   ```text
   #2563eb
   ```

2. Use white as the main page/card color.
3. Use one accent color, preferably green:

   ```text
   #16a34a
   ```

4. Add fade-in animation when results appear.
5. Add shadows to cards and buttons.
6. Improve spacing and typography.
7. Make the layout responsive on mobile.
8. Make buttons easy to tap on mobile.
9. Keep the design professional for a small business audience.
10. Keep the calculator icon or visual mark in the title.
11. Keep exact footer text:

    ```text
    Built with Claude Code
    ```

SEO requirements:

1. Verify the page has a descriptive title.
2. Verify the page has a meta description.
3. Verify headings are ordered logically.
4. Use semantic sections.

Accessibility requirements:

1. Labels must be connected to inputs.
2. Tooltip content must be available through accessible text.
3. Focus states must be visible.
4. Error messages must be readable.
5. Color must not be the only way errors/success are communicated.

JSDoc requirements:
Add or improve JSDoc for:

- calculation functions
- validation functions
- formatting functions
- chart rendering
- AI fetch
- localStorage save/restore
- PDF generation
- share URL handling
- reset handling

Validation:

1. Test desktop layout.
2. Test narrow mobile width.
3. Test valid calculation.
4. Test invalid input.
5. Test chart.
6. Test AI recommendation.
7. Test PDF.
8. Test share URL.
9. Test localStorage restore.
